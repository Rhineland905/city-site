# city-site

Сайт підземного міста на Minecraft-сервері в стилі Глибокої темряви.

Сайт працює тут: **https://city-site-ak6.pages.dev**

- **Мапа.** 2D-мапа за ігровими координатами X/Z з кількома шарами («Підземне місто», «Поверх 2» тощо). Мапу можна намалювати просто на сайті зі схематика всього міста, зрізом на потрібній висоті, або завантажити готову картинку (uNmINeD, Xaero's World Map). Якщо додати `.jar` своєї версії гри, блоки на мапі будуть справжніми текстурами Minecraft (16 пікселів на блок). Центр міста позначено міткою, координати в `public/config.js`.
- **Мітки.** На мапі можна ставити мітки з назвою, типом (будинок, ферма, склад, шахта, портал, торгівля, небезпека, інше), координатами й описом: «+ Мітка», потім клік по мапі, або правий клік → «Поставити мітку тут». Мітки можна перетягувати, а кнопка «Мітки» відкриває список із пошуком і фільтром за типом. Мітки з Y видно і в 3D.
- **Жива мапа.** Мод для Minecraft 26.3 (Fabric) сам оновлює мапу: коли гравець із модом ходить містом, прогружені чанки за хвилину з’являються на сайті з текстурами як у грі. Редактор може додати області: вони розширюють територію, яку оновлює мод, і можуть мати свій зріз, щоб показати поверх нижче чи вище.
- **3D.** Шар, намальований зі схематика, можна покрутити в 3D: порода ховається, ліхтарі світяться, а повзунок зрізає місто за висотою, щоб зазирнути на нижні поверхи. Мітки схематиків клікабельні.
- **Схематики.** Можна завантажувати `.schem`, `.litematic`, `.schematic` і `.nbt` з координатами X/Y/Z та виміром. Кожен схематик можна скачати, подивитися в 3D, скопіювати до нього `/tp` або відкрити на BlueMap сервера.
- **Завдання.** Дошка «Треба зробити / У роботі / Готово», картки можна перетягувати. Перше завдання вже лежить на дошці: як завантажити мапу міста.
- **Доступ.** Дивитися й скачувати може будь-хто. Щоб завантажувати й редагувати, треба увійти з паролем редактора (один спільний пароль).

## Безкоштовний хостинг 24/7

Сайт працює на Cloudflare, це безкоштовно й без прив’язки картки:

| Що | Де | Безкоштовний ліміт |
| --- | --- | --- |
| Сторінки сайту | Cloudflare Pages | без ліміту трафіку |
| API (`functions/`) | Pages Functions | 100 000 запитів на день |
| Схематики, картинки мап, 3D-моделі | Workers KV | 1 ГБ, файл до 25 МБ, 1 000 завантажень на день |
| Список схематиків, завдання, шари | D1 (SQLite) | 5 ГБ |

Сайт не «засинає», як безкоштовні Render чи Heroku. R2 не використовується, бо для нього Cloudflare просить прив’язати картку.

## Як запустити на Cloudflare (один раз, хвилин 10)

1. Зареєструйся на [dash.cloudflare.com](https://dash.cloudflare.com), це безкоштовно.
2. **Storage & Databases → D1 → Create.** Назви базу `city-site`. Таблиці сайт створить сам під час першого запуску.
3. **Storage & Databases → KV → Create.** Назви сховище `city-site-files`.
4. **Workers & Pages → Create → Pages → Connect to Git** (або «Import an existing Git repository»). Вибери репозиторій `city-site`.
   - Framework preset: `None`
   - Build command: залиш порожнім
   - Build output directory: `public`
   - Натисни **Save and Deploy**.
5. У проєкті відкрий **Settings → Bindings** і додай дві прив’язки:
   - **D1 database**: ім’я змінної `DB`, база `city-site`
   - **KV namespace**: ім’я змінної `FILES`, сховище `city-site-files`
6. **Settings → Variables and Secrets → Add**: тип *Secret*, ім’я `EDIT_PASSWORD`, значення = пароль редактора. Його потім роздаси тим, хто завантажуватиме схематики.
7. **Deployments →** біля останнього деплою натисни **Retry deployment**, щоб прив’язки застосувалися.
8. Сайт відкриється за адресою на кшталт `https://city-site.pages.dev`. Свій домен можна підключити в **Custom domains**.

Після цього кожен push у `main` оновлює сайт сам.

## Перша мапа міста

1. Відкрий сайт, натисни **Увійти** й введи пароль редактора.
2. На вкладці «Мапа» натисни **Мапа зі схематика** й вибери схематик усього міста (`.litematic` з Litematica).
3. Щоб блоки були як у грі, вибери ще й `.jar` своєї версії: `%APPDATA%\.minecraft\versions\1.21.4\1.21.4.jar` (на Mac `~/Library/Application Support/minecraft/versions/…`). Файл не завантажується на сайт: з нього в браузері малюється мапа й рахуються кольори блоків для 3D.
4. Впиши менші X, Y і Z з двох кутів виділення (Corner 1 і Corner 2 в Area Editor). Якщо перемальовуєш наявний шар, вони вже стоять.
5. Зріз підбирається сам: від підлоги до верху будинків. Його можна поправити, прев’ю одразу покаже результат.
6. Збережи шар. Перемикач **2D / 3D** з’явиться поруч із вибором шару.

Інші способи (Xaero's World Map, BlueMap через адміна) описані в завданні «Завантажити мапу міста» на сайті.

## Жива мапа (мод для гри)

Мод лежить у `mod/`, готовий файл: `public/mod/city-map.jar` (на сайті кнопка «Скачати мод» у вікні «Жива мапа»).

Гравцю:

1. Постав [Fabric Loader](https://fabricmc.net/use/installer/) для 26.3 і [Fabric API](https://modrinth.com/mod/fabric-api).
2. Поклади `city-map.jar` у `.minecraft/mods`.
3. На сервері напиши в чат `/citymap key КЛЮЧ` (ключ дає редактор). Далі мод працює сам: малює прогружені чанки в межах мапи й надсилає змінені. `/citymap` показує стан, `/citymap now` перемальовує все навколо, `/citymap off` вимикає.

Редактору (вікно «Жива мапа»):

- **Ключ.** «Створити ключ» один раз показує команду для гравців. Новий ключ скасовує старий.
- **Шари.** Галочка вмикає живу мапу на шарі, «згори» і «знизу» задають зріз за висотою, як у «Мапі зі схематика».
- **Області.** «+ Область», потім два кліки по кутах на мапі. Область рівняється до чанків, і мод оновлює її навіть за межами мапи міста. У кожної області свій зріз: постав нижче чи вище, щоб показати інший поверх. Редактор бачить області на мапі пунктиром (фіолетовим, якщо зріз свій), ярлик у кутку відкриває налаштування. Разом до 4096 чанків на шар.

Зібрати мод: `cd mod && ./gradlew build` (потрібна Java 25), файл з’явиться в `mod/build/libs/`. `./gradlew runClientGameTest` запускає гру, будує тестову сцену й малює її чанки.

## Будова

- `public/`: сам сайт (без збирання). Leaflet і three.js лежать у `public/vendor/`, щоб сайт не залежав від чужих CDN.
  - `app.js`: інтерфейс; `schem.js`: читання `.schem`/`.litematic` і мапа зрізу; `textures.js`: текстури й моделі блоків із `.jar` гри та мапа з текстурами; `voxel.js`: 3D; `blocks.js`: кольори блоків, коли текстур немає.
- `functions/api/[[path]].js`: увесь API (схематики, завдання, шари мапи, мітки, жива мапа, вхід).
- `mod/`: мод для гри (Fabric, Java 25). `LiveMap` стежить за прогруженими чанками й надсилає змінені, `ChunkRenderer` і `BlockTops` малюють чанк згори текстурами з моделей гри, `SiteApi` говорить із сайтом.
