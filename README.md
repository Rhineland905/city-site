# city-site

Сайт подземного города на Minecraft-сервере в стиле Глубокой тьмы.

- **Карта.** 2D-карта по игровым координатам X/Z с несколькими слоями («Подземный город», «Этаж 2» и т.д.). Карту можно нарисовать прямо на сайте из схематика всего города, срезом на нужной высоте, или загрузить готовую картинку (uNmINeD, Xaero's World Map).
- **3D.** Слой, нарисованный из схематика, можно покрутить в 3D: порода скрывается, фонари светятся, а ползунок срезает город по высоте, чтобы заглянуть на нижние этажи. Метки схематиков кликабельны.
- **Схематики.** Можно загружать `.schem`, `.litematic`, `.schematic` и `.nbt` с координатами X/Y/Z и измерением. Каждый схематик можно скачать, посмотреть в 3D, скопировать к нему `/tp` или открыть на BlueMap сервера.
- **Задачи.** Доска «Нужно сделать / В работе / Готово», карточки можно перетаскивать. Первая задача уже лежит на доске: как загрузить карту города.
- **Доступ.** Смотреть и скачивать может кто угодно. Чтобы загружать и править, нужно войти с паролем редактора (один общий пароль).

## Бесплатный хостинг 24/7

Сайт работает на Cloudflare, это бесплатно и без привязки карты:

| Что | Где | Бесплатный лимит |
| --- | --- | --- |
| Страницы сайта | Cloudflare Pages | без лимита по трафику |
| API (`functions/`) | Pages Functions | 100 000 запросов в день |
| Схематики, картинки карт, 3D-модели | Workers KV | 1 ГБ, файл до 25 МБ, 1 000 загрузок в день |
| Список схематиков, задачи, слои | D1 (SQLite) | 5 ГБ |

Сайт не «засыпает», как бесплатные Render или Heroku. R2 не используется, потому что для него Cloudflare просит привязать карту.

## Как запустить на Cloudflare (один раз, минут 10)

1. Зарегистрируйся на [dash.cloudflare.com](https://dash.cloudflare.com), это бесплатно.
2. **Storage & Databases → D1 → Create.** Назови базу `city-site`. Таблицы сайт создаст сам при первом запуске.
3. **Storage & Databases → KV → Create.** Назови хранилище `city-site-files`.
4. **Workers & Pages → Create → Pages → Connect to Git** (или «Import an existing Git repository»). Выбери репозиторий `city-site`.
   - Framework preset: `None`
   - Build command: оставь пустым
   - Build output directory: `public`
   - Нажми **Save and Deploy**.
5. В проекте открой **Settings → Bindings** и добавь две привязки:
   - **D1 database**: имя переменной `DB`, база `city-site`
   - **KV namespace**: имя переменной `FILES`, хранилище `city-site-files`
6. **Settings → Variables and Secrets → Add**: тип *Secret*, имя `EDIT_PASSWORD`, значение = пароль редактора. Его потом раздашь тем, кто будет загружать схематики.
7. **Deployments →** у последнего деплоя нажми **Retry deployment**, чтобы привязки применились.
8. Сайт откроется по адресу вида `https://city-site.pages.dev`. Свой домен можно подключить в **Custom domains**.

После этого каждый push в `main` обновляет сайт сам.

## Первая карта города

1. Открой сайт, нажми **Войти** и введи пароль редактора.
2. На вкладке «Карта» нажми **Карта из схематика** и выбери схематик всего города (`.litematic` из Litematica).
3. Впиши меньшие X, Y и Z из двух углов выделения (Corner 1 и Corner 2 в Area Editor).
4. Задай срез: «сверху» чуть ниже потолка этажа, «снизу» на уровне пола. Превью сразу покажет результат.
5. Сохрани слой. Переключатель **2D / 3D** появится рядом с выбором слоя.

Другие способы (Xaero's World Map, BlueMap через админа) описаны в задаче «Загрузить карту города» на сайте.

## Настройки

`public/config.js`: название города и адрес BlueMap сервера. Поменяй и закоммить.

## Локальный запуск

```bash
npm install
npm run dev   # http://localhost:8788, пароль редактора: test
```

## Устройство

- `public/`: сам сайт (без сборки). Leaflet и three.js лежат в `public/vendor/`, чтобы сайт не зависел от чужих CDN.
  - `app.js`: интерфейс; `schem.js`: чтение `.schem`/`.litematic` и карта среза; `voxel.js`: 3D; `blocks.js`: цвета блоков.
- `functions/api/[[path]].js`: весь API (схематики, задачи, слои карты, вход).
